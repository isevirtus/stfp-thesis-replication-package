# TeamPlus Thesis Replication Package

Pacote de replicação e materiais suplementares da tese sobre formação de equipes de software guiada por conhecimento especializado e busca evolutiva.

Este repositório organiza planilhas, resultados agregados, scripts auxiliares e materiais de auditoria usados nos experimentos. Dados industriais sensíveis devem permanecer anonimizados ou agregados.

## Estrutura

- 00_documentacao_geral: documentação suplementar e materiais gerais.
- 01_calibracao_bn: calibração da Rede Bayesiana.
- 02_fidelidade_surrogate: comparações entre surrogate e BN.
- 03_calibracao_ga: calibração do Algoritmo Genético.
- 04_milp_vs_ga: comparações entre MILP/ILP e GA.
- 05_backtest_historico: backtest com equipes históricas.
- 06_baselines_algoritmicos: baselines algorítmicos e comparações com média simples.
- 07_llm_vs_ga: comparações entre LLM e GA.
- 08_validacao_autoridade: materiais da validação com autoridade decisória.
- 09_refinamento_pos_validacao: scripts, entradas, resultados e auditorias do refinamento pós-validação.
- 10_escalabilidade: experimentos de escalabilidade.
- 99_arquivados: duplicatas, variantes exploratórias e materiais preservados por rastreabilidade.
